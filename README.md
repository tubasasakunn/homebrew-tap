# tubasasakunn/homebrew-tap

個人用の Homebrew tap です。

## Casks

| Cask | 内容 |
| --- | --- |
| [`oreore-mac-widget`](https://github.com/tubasasakunn/oreore-mac-widget) | Claude Code の使用量（5時間セッション / 週次）を macOS のメニューバーに表示する常駐アプリ |

## 使い方

```sh
brew install --cask tubasasakunn/tap/oreore-mac-widget
```

tap を追加してから入れることもできます。

```sh
brew tap tubasasakunn/tap
brew install --cask oreore-mac-widget
```
